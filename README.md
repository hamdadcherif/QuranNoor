## QuranNoor 🌙📖

**QuranNoor** is a web platform created to make reading and exploring the Holy Quran simple, peaceful, and accessible.

I built QuranNoor as a special gift for **my mother and someone I love**. ❤️ It is a personal project that combines my passion for web development with something deeply meaningful to me — the Quran.

The project was built with **React**, with a focus on creating a clean, modern, and peaceful reading experience.

> **Built with code, faith, and love. 🤍**
